# Smart Radar with Camera Surveillance

## Project Overview
Smart Radar with Camera Surveillance is a low-cost security monitoring system developed using ESP32-CAM and a PIR motion sensor.

It detects human movement and provides a live camera view through a web browser using Wi-Fi.

## Objectives
- Detect human movement.
- Monitor the surrounding area using a camera.
- Display motion status.
- Provide a low-cost surveillance solution.

## Hardware Components
- ESP32-CAM Module
- ESP32-CAM-MB Programmer Board
- PIR Motion Sensor
- LM2596 Step-Down Module

## Software Requirements
- Arduino IDE
- ESP32 Board Package
- Web Browser

## Technologies Used
- Embedded C/C++
- ESP32
- Wi-Fi
- IoT

## Working Principle
1. PIR sensor detects human movement.
2. ESP32-CAM receives the motion signal.
3. Flash LED turns ON when motion is detected.
4. Camera captures the monitored area.
5. Live camera view is displayed through a web browser.

## Features
- Motion detection
- Live camera monitoring
- Wi-Fi connectivity
- Motion status display
- Low-cost security system
